# 杜比人回忆网站

这是一个可以直接部署到 GitHub Pages 的单页网站。

## 文件结构

- `index.html`：页面、样式和交互
- `assets/photo-01.jpg` ～ `assets/photo-05.jpg`：五张回忆照片

## 背景音乐

页面使用 Web Audio 在浏览器内生成原创配乐，不依赖外部音频文件，也不存在热门歌曲版权风险。音乐速度会在 92～114 BPM 之间随叙事变化，以马林巴主题为主，加入少量钢琴、更清晰的架子鼓、和声、低音与圆号；“漂浮、甚至很假”处会主动抽掉节奏并转暗，结尾再升调回归完整主题。访客主动点击“播放音乐”后才会开始，并且可以随时暂停。

## 交互

- 逐张设置人物焦点的照片弹层，支持按钮、键盘和手机滑动翻页
- “给彼此加一点电”和“走一步”的即时反馈控件
- 不跳转正文的“主线 / 分支”动态解释地图与路线小游戏
- 带段落聚焦、进度反馈的立体正文卡片
- 明确的阅读完成确认和页面结束标志
- 真实照片加载进度、顶部阅读进度和当前章节提示
- 尊重 `prefers-reduced-motion` 的动态效果
