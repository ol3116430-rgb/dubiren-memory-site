# 杜比人回忆网站

这是一个可以直接部署到 GitHub Pages 的单页网站。

## 文件结构

- `index.html`：页面、样式和交互
- `assets/photo-01.jpg` ～ `assets/photo-05.jpg`：五张回忆照片
- `assets/audio/dubiren-theme.mp3`：网页优化后的正式配乐 `Warm Horizon`

## 背景音乐

页面使用用户提供的 `Warm Horizon` 正式音轨。原始 MP3 已移除封面和冗余元数据，并压缩为约 4.3MB 的 44.1kHz 立体声网页版本。页面根据音轨本身的音量和结构划分七个叙事段落，滚动到不同章节时会先渐隐、切换到对应段落，再渐入；不会自动播放，也不会叠加播放，访客可以随时暂停并保留当前位置。

## 交互

- 逐张设置人物焦点的照片弹层，支持按钮、键盘和手机滑动翻页
- “给彼此加一点电”和“走一步”的即时反馈控件
- 不跳转正文的“主线 / 分支”动态解释地图与路线小游戏
- 带段落聚焦、进度反馈的立体正文卡片
- 明确的阅读完成确认和页面结束标志
- 真实照片加载进度、顶部阅读进度和当前章节提示
- 尊重 `prefers-reduced-motion` 的动态效果
