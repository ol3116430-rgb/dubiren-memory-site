# 杜比人回忆网站

这是一个可以直接部署到 GitHub Pages 的单页网站。

## 文件结构

- `index.html`：页面、样式和交互
- `assets/photo-01.jpg` ～ `assets/photo-05.jpg`：五张回忆照片
- `assets/bgm.mp3`：可选背景音乐（当前未放入）

## 添加背景音乐

1. 准备一段有权使用的音乐，建议使用 MP3 格式并控制在 5 MB 以内。
2. 将文件命名为 `bgm.mp3`。
3. 上传到仓库的 `assets/` 文件夹。

页面不会自动播放音乐。访客主动点击右上角“播放音乐”后才会播放，并且可以随时暂停。
